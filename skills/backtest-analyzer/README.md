# 📊 Backtest Analyzer

## 快速开始
```bash
# 查看帮助
python3 scripts/*.py --help
```

## 功能
回测分析工具。
* 从交易记录CSV计算回测核心指标：胜率、盈亏比、最大回撤、夏普比率、获利因子、单笔最高/最低盈亏交易。
* 支持JSON报告导出。
