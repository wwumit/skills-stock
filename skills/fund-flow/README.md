# 💹 Fund Flow

## 快速开始
```bash
# 查看帮助
python3 scripts/fund_flow.py --help

# 排行分析
python3 scripts/fund_flow.py --file fundflow.csv

# 趋势检测 + 板块
python3 scripts/fund_flow.py --file fundflow.csv --trend --sector --sector-col 板块
```

## 功能
资金流向分析工具 v1.1.0。排行分析、趋势检测、板块聚合、多时间维度、指数对比、强度评分、ASCII趋势图。
