# 💰 Trade Tracker

## 快速开始
```bash
# 查看帮助
python3 scripts/trade_tracker.py --help

# 基本分析
python3 scripts/trade_tracker.py --file trades.csv

# 月度归因 + 成本 + 持仓
python3 scripts/trade_tracker.py --file trades.csv --by month --cost --hold
```

## 功能
交易追踪与归因分析 v1.1.0。交易复盘、成本分析、持仓结构、策略标签、多策略对比、ASCII盈亏分布图。
